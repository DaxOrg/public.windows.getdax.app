# Dax for Windows

[Download Dax](https://github.com/DaxOrg/public.windows.getdax.app/releases)

Requires Windows 11 x64 and the [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/).

1. Download the ZIP and `SHA256SUMS.txt` from the release.
2. Extract the entire ZIP to a permanent folder.
3. Run `Dax.exe`. Keep its accompanying files together.

The preview is unsigned. Verify the download and checksum before proceeding through any Windows warning. Do not disable Windows security protections.

Updates appear in Releases. Report problems in [Issues](https://github.com/DaxOrg/public.windows.getdax.app/issues).

This repository distributes the application only. Required third-party license notices are included with the download.
